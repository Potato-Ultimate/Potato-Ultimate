## Currently Building

### Distributed File Storage System

A distributed storage system designed to explore the engineering behind:

* File chunking and distribution
* Replication
* Fault tolerance
* Metadata management
* Node failure & recovery
* Concurrent access
* Distributed communication
* Scalable storage architecture

> The goal isn't just storing files — it's understanding what happens when machines fail.
