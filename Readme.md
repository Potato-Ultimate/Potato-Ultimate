### Distributed File Storage System

`Java 21` · `Spring Boot` · `PostgreSQL` · `Spring Data JPA`

A file storage prototype simulating a multi-node architecture with chunking, replication, centralized metadata management, and replica-aware reconstruction.

<table>
<tr>
<td width="50%">

**01 — Chunking**

Splits uploaded files into 1 MB chunks.

</td>
<td width="50%">

**02 — Replication**

Maintains two copies of each chunk across three logical storage nodes.

</td>
</tr>
<tr>
<td width="50%">

**03 — Metadata**

Tracks files, chunks, and storage locations using PostgreSQL.

</td>
<td width="50%">

**04 — Reconstruction**

Uses primary chunks when available and falls back to replicas when a primary chunk is missing.

</td>
</tr>
</table>

**Engineering focus:** Storage architecture, data placement, replication, metadata management, and failure scenarios.

<sub>Note: The current implementation simulates multiple nodes using separate local storage directories, rather than independent network-connected servers.</sub>
